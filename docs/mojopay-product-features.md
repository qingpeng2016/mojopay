# MojoPay 全球支付通道 · 产品功能（V1）

MojoPay 承上启下：向上对接支付渠道（首期 [Gate Pay](gate.txt)），向下以 OpenAPI 与品牌收银台服务商户。上游为机构主账号与子账号；下游为商户主/子账号，可多对多绑定上游能力（**优先级 + 权重**选路）。真实资金在上游账户，平台维护**虚拟账本**。库表见 [all.sql](all.sql)。

**优先级：** P0 联调前置；P1 为 V1 闭环。

**V1 主链：** 开通绑定 → 建单收银台 → 回调入账 → 结算 / 商户提现（含收 BTC 结法币、收法币结 BTC/稳定币，以上游开通为准）。

---

## 1. 上游管理

| 功能 | 功能描述 | 优先级 |
| --- | --- | --- |
| 上游商家 | 名称、官网、沙盒/生产 API 根地址、文档链接、启用状态 | P0 |
| 主/子账号 | 上游机构账号树、外部编号、状态 | P0 |
| 凭据与回调 | 密钥引用、回调 URL、出款 IP 白名单 | P0 |
| 通道能力 | 收款/换汇/出款、资产、地区、限额；未开通则关闭 | P0 |
| 余额流水 | 运营查看上游余额与流水回调处理进度 | P1 |
| 订单记录 | 经本上游的收款尝试与退款单 | P1 |

## 2. 下游商户

| 功能 | 功能描述 | 优先级 |
| --- | --- | --- |
| 商户主数据 | 编码、法定名称、国家、类别、准入状态 | P0 |
| 主/子账号 | 签约主体与子账号隔离 | P1 |
| 品牌 | 收银台 Logo、颜色、语言、回跳 URL | P1 |
| 通道绑定 | 绑上游子账号+能力；优先级、权重、费率、生效期 | P1 |
| API / Webhook | 密钥、权限、限流、HTTPS 回调 | P1 |
| 受益账户 | 提现用银行/链上地址，审核后可用 | P1 |

## 3. 资质

| 功能 | 功能描述 | 优先级 |
| --- | --- | --- |
| 商户 KYB | 主体材料与审核；影响可绑能力 | P1 |
| 用户 KYC | 按规则对 `external_user_id` 发起核验 | P1 |

## 4. 路由与收款

| 功能 | 功能描述 | 优先级 |
| --- | --- | --- |
| 路由与报价 | 筛绑定/资质/金额；权重选路；跨资产报价 | P1 |
| 建单与收银台 | 幂等建单；唯一有效支付链接；BTC 动态地址 | P1 |
| 法币/Gate 支付 | 已开通能力内跳转或托管页 | P1 |
| 订单与退款 | 查询与时间线；少付/晚到人工复核；退款 | P1 |

## 5. 账本、结算、对账

| 功能 | 功能描述 | 优先级 |
| --- | --- | --- |
| 虚拟账本 | 待结算/可用/冻结；收款与费用分录 | P1 |
| 结算与提现 | 结算单；商户提现；上游出款状态 | P1 |
| 对账 | Inbox、回调重试；流水差异人工处理 | P1 |

## 6. 下游 OpenAPI（V1）

| 功能 | 功能描述 | 优先级 |
| --- | --- | --- |
| 鉴权 | API Key + HMAC 签名 + 时间戳/Nonce；写操作幂等键 | P1 |
| 支付 | 支付方式、报价、建单、查单、退款 | P1 |
| 资金 | 余额、结算单、商户提现及查单 | P1 |
| 资质 | KYC 会话创建与查询 | P1 |
| Webhook | `payment.paid` 等事件；验签与重试 | P1 |
